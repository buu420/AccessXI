# AccessXI v2026.09.05

This release brings the current installed mission and navigation reader into the public installer and adds automatic support reports for mission, quest and zone problems.

- Memory Streams in Promyvion are no longer classified as enemy obstacles. Existing evidence requirements for open, closed and unknown Streams are preserved.
- Old saved step-completion records no longer skip instructions when that step contains multiple material actions. Migration resumes at the first action of an ambiguous step.
- The installer includes the current mission progress, objective speech and navigation modules, Promyvion transition data, and the pinned La Theine walk graph. Packaging now checks every literal module reference and the required navigation data before producing an installer.
- Mission, quest, navigation and speech diagnostics are recorded automatically in bounded support logs. Type `/axi report` after a problem to create `AccessXI-support-report.log` in the reader's `logs` folder. Send that file with a short description of what happened and approximately when. No debug command is needed before playing.
- Public packages exclude character packet caches, recorded personal progress, logs, backups and local Ashita configuration.

For a default installation, the report is under `%USERPROFILE%\AccessXI\Ashita\addons\accessxi_reader\logs`. It combines the current and previous 8 MiB segments and adds a fresh state snapshot. If the game cannot run, send `ffxi-support.log` and `ffxi-support.log.previous` if present. Reports can contain character names and game chat; review them before sharing.

Promyvion remains under testing: Holla has live evidence through the first forward Stream onto floor two. Its complete Spire route and traversal in Dem, Mea and Vahzl are not yet verified, and a Holla floor-two wall-contact case remains open. A support report supplies evidence for investigation; some problems will still need a focused in-game retest.

Use **AccessXI.Installer.exe** for installation. **AccessXI-Ashita-Installer.zip** is also the asset used by the built-in updater. See **setup-guide.md** for setup and troubleshooting.
