# AccessXI v2026.09.07

In The Heart of the Matter, Pore-Ohre could give the Southeastern star charm
while the objective continued pointing back to him. The saved cursor was on
an earlier travel instruction. Two guide entries described the same NPC
conversation, and neither compact action carried the key item that proved it
complete. The unchanged native mission number could not resolve that mismatch.

The shared progression code now carries an explicitly promised, uniquely
resolved NPC key item into the action's completion evidence. Duplicate heading
and conversation actions share that evidence and complete together. Acquisition
can catch up through their approach instructions; it cannot skip another NPC,
combat, a trade, a wait, transport, or a separate action needing the same item.
Dialogue alone cannot complete a step carrying a promised reward.

This applies to 18 reward groups in the shipped nation guides, including Dark
Key, Sword Offering and Dull Sword steps in Bastok. Identically named native
items, such as the three letters to the consuls, remain ambiguous. Unsupported
wording and missing compact actions are not claimed as covered.

Already completed conversations can recover from retained local support logs.
Recovery requires the same character and active native nation mission, their
triggered NPC event, a matching final event end, and the reward within 30 seconds.
The current client must also confirm the exact key item is still held using a
complete current-session packet. The NPC must match the current guide action.
Logs are read as data, within the existing file-size bounds. Recovery does not
rewind a later cursor or infer progress from cached inventory alone.

Automatic mission and zone diagnostics remain enabled. Interaction refusals now
include the durable cursor and blocking action; acquisition records include the
native item ID and completion boundary. Recovery logs distinguish a missing
current snapshot from scanned evidence. `/axi report` exports the support log.
