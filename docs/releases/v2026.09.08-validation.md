# AccessXI v2026.09.08

The Heart of the Matter could finish Pore-Ohre's conversation and then say
"Enter the tower" with no destination. The submitted v2026.09.07 report shows
that refusal beside Marguerite Tower in East Sarutabaruta. The guide had lost
the location context for this instruction and the following gizmo interactions.

Reviewed action bindings now cover the Manustery Apururu, Pore-Ohre, the
Marguerite entrance, all six orb placements, the energizing gate, all six
retrievals, and the return to Apururu. They use native destination identities
and explicit cutscene pairs. The return uses the Manustery Apururu; unrelated
Trust dialogue does not advance the mission. The tower entry completes on the
zone transition, not on reaching its outside mouth.

The shared interaction progress journal records distinct objects for an
objective. Completed gizmos disappear from the route choices, progress is
spoken as a count, and those identities survive reload. Duplicate interactions,
the opposite orb phase, another character, an old session, and failed saves
cannot spend a completion. Marking the objective done confirms the whole set;
undo preserves earlier native placements. Mark/undo journal rows also stop
accidentally appending the extra return value from Lua's string cleanup.

The existing live door navigator now recognizes the exact target name Cracked
Wall while retaining its type-3 entity requirement, route corridor, distance,
and debounce checks. It speaks the ordinary target-and-open controls and keeps
the route through the opening. Merely opening a wall does not count as a gizmo.
The catalog classifies the ruins' gizmos and cracked walls as objects.

Automatic mission and zone diagnostics remain enabled. The support log now
includes each accepted gizmo identity, event, phase and count. `/axi report`
continues to export the diagnostic log for support. Missing reviewed locations
retain the useful instruction and explain the missing installation data;
unreachable current zones do not promise a route.
